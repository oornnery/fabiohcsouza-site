## One question at a time

Start with something you can answer in one session: "what changes if I switch the codec?" or "how long does this route take with 100 items?".

## Change only one condition

If you change two things at once, you can't tell which one caused the result. Write down the starting state before touching anything.

## Write down the result

```md lab.md
## Question
## Condition changed
## Expected result
## Actual result
## What to do next
```

Five lines are enough. Over time, these notes become the best study material you have.
