## The project

One page per component, each with content variations: short and long titles, an empty list, a validation error, text that wraps.

## What gets tested

- Semantics: the right element for each action.
- Keyboard and visible focus.
- Behavior when the content grows or disappears.

## Decisions

- Plain HTML and CSS; JavaScript only when the behavior requires it.
- Real content in the examples, never lorem ipsum.
