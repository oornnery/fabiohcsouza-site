## O projeto

Uma página por componente, cada uma com variações de conteúdo: título curto e longo, lista vazia, erro de validação, texto que quebra linha.

## O que é testado

- Semântica: o elemento certo para cada ação.
- Teclado e foco visível.
- Comportamento quando o conteúdo cresce ou some.

## Decisões

- HTML e CSS puros; JavaScript só quando o comportamento exige.
- Conteúdo real nos exemplos, nunca lorem ipsum.
